# 演示脚本（约 8 分钟）

## 演示前准备

```bash
npm install
npm run db:migrate
npm run db:seed
npm run db:seed:english
cd web && npm install && npm run build
cd ..
npm start
```

打开 http://localhost:3000

演示账号：

- 学生：`student02` / `Stud@123`
- 教师：`teacher1` / `Teach@123`
- 管理员：`admin` / `Admin@123`

## 演示流程

### 1. 学生练习与即时解析（约 2 分钟）

1. 学生登录，进入「练习中心」
2. 选择「英语A级」，题量 5，开始练习
3. 答一题后提交，展示：对错、正确答案、解析
4. 切换到「主观题（翻译 / 写作）」
5. 写一段翻译，提交后展示参考答案
6. 点「还需要练」，说明该题进入错题本

### 2. 错题本与重做（约 1 分钟）

1. 进入「错题本」
2. 展示错题、你的答案、正确答案、解析
3. 点「重做这道」，答对后返回错题本
4. 说明：最近一次答对自动移出，历史记录仍保留

### 3. 模拟考试（约 2 分钟）

1. 进入「模拟考试」
2. 选英语A级、10 题、30 分钟，开始
3. 展示：倒计时、答题卡、自动保存
4. 答几题后交卷
5. 展示：立刻出总分、正确率、逐题对错与解析

### 4. 教师阅卷（约 1.5 分钟）

1. 退出，教师登录
2. 进入「阅卷中心」，选择英语A级模拟考试
3. 打开一条学生答卷，展示学生答案与参考答案
4. 给主观题打分，保存
5. 点「保存全部并合成成绩」，展示客观分 + 主观分 = 总分

### 5. 统计与导出（约 1 分钟）

1. 进入「统计分析」
2. 展示概览：应交、已交、已出分、平均分、及格率
3. 切换「题目分析」「知识点掌握」，展示图表
4. 点「导出成绩 CSV」

### 6. 断网验证（约 0.5 分钟）

1. 断开网络
2. 刷新页面，重复一次练习/模拟考试
3. 说明：页面与接口全部在本机，未依赖任何外部服务

## 演示要点

- 双快照：发布试卷后修改题库，试卷内容不变
- 状态机：考试按时间窗自动从「未开始」进入「进行中」
- 判分矩阵：五种题型、多选顺序无关、填空同义答案
- 错题本以「最近一次作答」为准
- 监督接口预留但默认关闭，不向外部发送任何请求

## 已知限制（如被问到）

- 教师端「试卷管理 / 考试管理」页面仍是占位页，后端接口与种子数据已完成
- 听力题暂不支持
- 简答题不自动判分，由教师人工评分
