# 测试报告

## 测试环境

- Node.js 24.16.0
- 测试框架：Node 内置 `node:test`
- HTTP 断言：supertest
- 数据库：每个测试文件独立的临时 SQLite 文件（自动创建、自动清理），不触碰开发数据库
- 运行命令：`npm test`

## 测试清单

### 单元测试 `server/tests/unit/normalize.test.js`

| 用例 | 覆盖点 |
|---|---|
| normalizeText | 去空白、大小写、全角空格 |
| normalizeChoice | 多选排序、去空 |
| 单选题 | 大小写不敏感、错误答案 |
| 多选题 | 顺序无关、漏选/多选判错 |
| 判断题 | true/false 判分 |
| 填空题 | 同义答案（`8|八`）、多空、空答案 |
| 简答题 | 返回 null，不自动判分 |
| 空答案 | null、空串、空数组 |

### 集成测试

**`auth.test.js`**

- 健康检查
- 管理员登录 / 获取当前用户
- 错误密码 401
- 学生访问用户管理 403
- 教师只能看到自己带的班级
- 修改密码后旧令牌失效、新密码可登录
- 禁用账号无法登录

**`question.test.js`**

- 题库列表分页
- 创建单选题并自动归一化答案
- 单选两个正确项返回 422
- CSV 导入逐行结果（2 行成功）
- CSV 导出包含表头与 BOM
- 教师不能修改其他教师创建的题目

**`examFlow.test.js`**

- 创建试卷 → 加大题 → 加题
- 总分自动汇总
- 发布后所有题目冻结快照
- 发布后修改题库，试卷内题干不变
- 创建考试 → 排期 → 学生可见并可开始
- 答题 → 自动保存 → 交卷 → 自动判分
- 发布成绩前学生不可见成绩
- 结束考试 → 发布成绩 → 学生可见总分、及格状态、逐题对错

**`practice.test.js`**

- 英语A级题库统计（21 道客观题）
- 随机抽题、答错/答对即时判分
- 练习统计（题量、正确率）
- 错题本收录
- 按题目 ID 重做
- 重做答对后自动移出错题本
- 主观题练习返回参考答案与记录 ID
- 主观题自评「还需要练」后进入错题本

**`mockExam.test.js`**

- 学生自主创建模拟考试（5 题）
- 自动保存答案
- 刷新后保留答案
- 交卷即时出分、逐题正确答案与解析
- 历史记录可查

**`gradingStats.test.js`**

- 创建简答题与试卷
- 学生作答含主观题的试卷，交卷后状态为「待阅卷」
- 阅卷列表显示待阅会话
- 会话详情返回主观题答案与参考答案
- 单题评分
- 合成成绩：客观分 + 主观分
- 统计概览、成绩单、排名、题目分析、知识点掌握、CSV 导出

**`audit.test.js`**

- 管理员可以分页查看审计日志
- 写操作会出现在审计日志中
- 教师访问审计日志返回 403
