# 开发日志

## 2026-10-25 · D1 地基

**完成**

- 项目初始化：Node 24 + Express 4，依赖全部为纯 JS 包，无原生编译
- 数据库：`node:sqlite`（Node 内置），20 张业务表，WAL 模式，外键约束
- 迁移器：`schema_migrations` 记录版本，支持重复执行
- 种子数据：11 个账号（1 管理员 / 2 教师 / 8 学生）、2 个班级、5 个知识点、10 道样题（覆盖五种题型）
- 基础层：统一响应格式、AppError 错误体系、JWT、密码哈希、分页、CSV、答案归一化、洗牌
- 中间件：requestId、鉴权、RBAC、Zod 校验、错误处理、审计日志、限流
- 业务模块：登录/登出/改密码、用户管理、班级与成员、知识点树

**验证**

- `GET /api/health` 返回 200，数据库状态 ok
- 三种角色登录成功；错误密码返回 401 `BAD_CREDENTIALS`
- 学生访问 `/api/users` 返回 403 `FORBIDDEN`
- 教师只能看到自己带的班级（teacher1 → 计算机 2401 班）
- 知识点树正确嵌套：计算机基础 → 数据结构 / 操作系统 / 计算机网络 / 数据库

**决策记录**

- 不用 better-sqlite3：本机 GitHub release 直连不通，原生模块安装风险高；改用 Node 内置 `node:sqlite`，零编译依赖
- 时间统一存毫秒时间戳，服务端计算所有截止时间，前端倒计时仅作展示
- 审计中间件跳过答案自动保存和作弊事件上报，避免高频写入

**前端**

- Vue3 + Vite + Element Plus 骨架，hash 路由 + 相对路径（WebView 兼容）
- 登录页（三角色演示账号一键填充）、主布局（侧边栏 + 移动端抽屉 + 用户菜单 + 修改密码）
- 概览页（按角色显示统计卡片与快捷入口）、用户管理页（筛选、分页、启停、新建）
- 未开发模块使用统一占位页
- `npm run build` 通过，Express 托管 `web/dist`，浏览器实测登录页渲染正常

## 2026-10-25 · D4 答题会话

**完成**

- 学生考试列表：只返回被指派班级的考试，带本次会话状态、剩余次数、是否可开始
- 开考：校验班级归属、时间窗、最大次数；创建会话并冻结本场题目快照
- 乱序：题目顺序与选项顺序按考试配置随机，落库保存，刷新后顺序不变
- 续考：同一考试存在进行中的会话时直接续考，已保存答案原样返回
- 自动保存：批量 UPSERT，带 `save_version` 递增；只允许保存属于本场的题号
- 防作弊：失焦、页面隐藏、退出全屏、复制、粘贴事件上报，客户端序号去重，违规计数
- 超时：服务端计算 `deadline = min(开考+时长, 考试结束时间)`，超时访问任意接口自动交卷
- 交卷：客观题即时判分并写回每题得分，含简答题时状态为「待阅卷」，否则直接「已出分」
- 成绩：考试未发布时学生只能看到「成绩尚未发布」，发布后显示逐题得分与正确答案

**验证**

- 开始考试得到 3 道题，题目顺序随机
- 保存 1 条答案后再次开考，返回同一会话且答案仍在
- 上报 `blur` 事件，违规计数变为 1
- 交卷自动判分：满分 15，答对单选与判断、多选漏选，得 10 分
- 发布前查询成绩返回 `published=false`；教师结束考试并发布后，学生看到 10 分、及格（及格线 9 分）、逐题对错
